# 実装記録

目的：iPhoneにインストールしてGRAVITYの新しいコメントを自分で聞くPRIVATEモード。ユーザーは実機での反復改善を了承。

1. 完了：既存の検証済み新着判定と待機列を再利用。30テストと24フレーム模擬入力をLinuxで確認。
2. 完了：アプリ、Upload拡張、同期Vision OCR、メインキューの音声処理、停止・再基準化を実装。
3. 完了：新規レビューでアプリ内配信の開始経路をシステム全画面配信ピッカーに変更。音声開始失敗を終了エラーとして通知。
4. 完了：Xcodeプロジェクトと依存なし生成スクリプト、署名・操作案内を作成。
5. 検証記録：validation.json に最新のApple CI結果を格納。

判断：システム全画面配信は設定拡張を経由しないため、App Groupsを必要としない固定OCR範囲を採用。実機のコメント位置が異なる場合は調整が必要。署名済み配布、GRAVITYの実機動作、ROOM音声経路を実装済みとは扱わない。
