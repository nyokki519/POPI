# GRAVITY Reader — iPhone PRIVATE実機検証版

iPhone自身の画面配信をReplayKit拡張で受け取り、Visionで日本語を認識して、新着の文字行を読み上げるネイティブiOSアプリです。Macはインストール時のXcodeビルドに必要ですが、使用中のMacへの画面転送は不要です。

## インストール

このZIPはXcodeプロジェクトです。**iPhoneでZIPを開くだけではアプリをインストールできません。署名済みIPA・TestFlight版ではありません。**

1. MacのXcodeで `GravityReader.xcodeproj` を開き、iPhoneを接続します。
2. `GravityReader` と `Upload` の両ターゲットで Signing & Capabilities の Team に自分のApple Accountを選びます。Bundle Identifier が使用済みなら、自分の固有名に変更します。Uploadは必ずアプリのIdentifierに `.Upload` を付けます。
3. Scheme `GravityReader` と接続したiPhoneを選んで ▶︎ Run。必要に応じてiPhoneで開発者モードと開発者の信頼を許可します。

Apple Accountの無料署名には期限と機能制限があり、期限後は再ビルドが必要です。このプロジェクトはApp Groupsやクラウドサービスを使いません。署名環境・無料アカウントでの実機インストールは未検証です。有料登録を要求・実行していません。

## 使用

1. アプリの画面配信ボタンを押し、`Gravity Reader PRIVATE` を選択して開始します。マイクはオフです。
2. GRAVITYを開きます。最初に映るコメントは基準画面となり、読み上げません。
3. 以後、2回の認識で確認された新しい文字行を読み上げます。
4. 停止はiPhone上部の画面配信表示、またはコントロールセンターから行います。

読取範囲は**縦画面の上から45〜90%**、約0.75秒間隔、読み上げ速度0.5に固定。実際のコメント欄がこの範囲にない場合は `Sources/Shared/Configuration.swift` の既定値を変えて再ビルドします。範囲設定UIはありません。画面レイアウトが変わるとコメント以外も認識されます。複数行コメントの結合は行わず、OCR文字行を単位とします。画面が完全に入れ替わった場合は再基準化するため、その間のコメントを読む保証はありません。混雑時は待機6件・8秒以内とし、古い読み上げは捨てます。

PRIVATEは自分で聞く用途です。**ROOMのマイク経路への音声注入は未実装**です。スピーカー音をマイクが拾う可能性を避けるためイヤホンを推奨します。

## 確認範囲

- 共通新着判定・待機列：30テスト、24フレーム模擬入力の検証。
- 設定値：既定値、上下逆転、非有限値、範囲外入力の検証。
- Apple CI：実際のiOS SDKでアプリとUpload拡張をビルドし、拡張の埋め込みを確認。結果は `validation.json` に記録します。
- **未検証**：署名済みiPhoneインストール、GRAVITY上のOCR精度、バックグラウンドで聞こえる読み上げ、GRAVITY音声ルームとの音声競合、拡張の実機メモリ制限。コンパイル成功はこれらの動作証明ではありません。

画面・認識文字の保存、ネット送信はしません。診断ログには認識行数・新着数・処理時間を記録し、コメント本文は記録しません。音声開始エラーや連続OCRエラーは配信を終了し、システムにエラーを返します。実機で無音の場合、配信継続、音量・イヤホン経路、GRAVITY音声ルームを閉じた場合の差を確認してください。

## 開発

Xcodeプロジェクトを同梱しています。Homebrew等の追加依存は不要です。`python3 scripts/generate-project.py` で再生成できます。Swiftがある環境では `bash scripts/test-core.sh` で純粋ロジックを検証できます。
