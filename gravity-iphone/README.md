# オカマ読み上げスッキリアプリ v0.5

iPhoneの画面配信から、左側の **画像アイコン・名前・その下の本文** の並びを探し、新着の本文を読み上げます。吹き出しの色や閉じた輪郭は必須条件にしていません。

[起動画面](preview-v0.5.jpg) ／ [Windowsからの導入](WINDOWS.md)

## 今回の変更

- 白・灰色に限定して吹き出しを探す方式から、文字の位置と左側の画像を照合する方式に変更しました。鮮やかな色、背景と同色、輪郭のない本文にも対応するための変更です。
- 名前の下の本文をまとめ、名前そのものは読み上げません。アイコンが対応しない枠・本文のない名前・右側の座席・下の入力欄を除外します。キーボードは繰り返し並ぶキーの形で除外します。
- アイコンは円形だけに限定せず、周囲との境界や画像の模様も利用します。装飾の全種類を確認したものではありません。
- 深いピンクの花とゴールドの音波を使うアプリアイコンを追加しました。iPhone・iPadの必要サイズを同梱し、配信拡張には画像を同梱しません。
- Windows用に、クラウドでビルドした署名前のIPAを用意します。AltStore Classicで個人署名して入れる手順は [WINDOWS.md](WINDOWS.md) を参照してください。Windowsでの実インストールは未検証です。

## 動作と負荷

位置だけで全てを読む方式には戻していません。広いチャット領域にVisionを1回実行し、文字・画像の配置に合致した本文だけを新着判定へ渡します。認識画像は長辺1280以下・40万画素以下、配置判定用画像は長辺640以下です。同じ画像の結果はメモリ内で最大12件再利用します。

通常1.2秒以上の間隔を空け、処理が重い場合や発熱時は間隔を延ばします。高温時は認識を見送ります。元のReplayKitバッファはコールバックを越えて保持しません。実機でのCPU・メモリ・発熱や旧版との速度比較は未確認です。新方式はOCR範囲が広いため、常に旧版より軽いとは限りません。

## Macからの導入・更新

フルZIPを展開し、新しい `GravityReader.xcodeproj` を開きます。以前の1ファイルだけのパッチは使いません。

1. `GravityReader` と `Upload` 両ターゲットの Signing & Capabilities → Team に自分のPersonal Teamを設定します。
2. 古いXcodeでdevice support files不足が出る場合は、実行先を **Any iOS Device (arm64)** にし、Product → Buildを実行します。
3. Product → Show Build Folder in Finder → Products → **Debug-iphoneos** の `GravityReader.app` を探します。
4. ⌘＋Shift＋2 → 接続したiPhoneを選び、ロック解除した状態で `.app` をInstalled Appsへドラッグします。必要ならiPhoneの設定 → 一般 → VPNとデバイス管理から自分の開発者を信頼します。

無料署名には期限があります。別のiPhoneにも、その端末用の署名が必要です。App Storeから全端末へ入れる配布版ではありません。有料開発者登録や課金は行っていません。Swift 5.7.2での共通ロジックのテストと、Apple SDKでのビルドを区別して記録します。完全なXcode 14.2での今回のビルドは未確認です。

## 使用

1. アプリの配信ボタンから「オカマ読み上げスッキリアプリ」を開始します。マイクはオフです。
2. GRAVITYのルームを開きます。最初に認識できた画面は基準とし、読みません。
3. 新しく出現し、2回確認した本文を読み上げます。
4. iPhoneの画面配信表示、またはコントロールセンターから停止します。

待機列は6件・8秒以内で、古い読み上げは捨てます。画面全体が入れ替わって既存本文との重なりがなくなった場合は再基準化するため、取りこぼす場合があります。PRIVATEは自分で聞く用途です。ルームのマイクへの音声注入は未実装です。

## 読まれない場合

画面配信を停止してから、アプリの **「読まれないときの確認」** を開きます。

1. 実際のルームのスクリーンショットを選びます。配信と同じ処理で認識した本文を表示します。緑枠は本文として抽出できた文字領域です。
2. 画面の文字0行なら文字認識の失敗、文字があるのに発言0件なら画像・名前・本文の対応付けの失敗です。v0.5では、この2つの件数を別に表示します。
3. 本文が出たら「認識した本文を試し読み」、音自体の確認には「音声だけテスト」を使います。

画像は選択したものだけを使用し、保存・外部送信しません。バックグラウンドに移ると診断画像を解放します。静止画での成功は、GRAVITY使用中のバックグラウンド動作を保証するものではありません。

## 検証と制限

実行結果・対象コミットは `validation.json` に記録します。

- 純粋Swift：新着・重複、待機列、24フレームの模擬入力、画像／名前／本文の有無、多色・輪郭なし・四角いアイコン、座席・入力欄・明暗キーボードの除外。
- Apple環境：生成画像を実際のVisionに渡す日本語OCR、複数解像度、名前を除く本文抽出、キャッシュ、向き、アプリと配信拡張のビルド。
- 未確認：GRAVITY実機での修正版の精度と音声、実際の課金装飾全種、Windowsでの署名・導入、全端末・将来のiOS版。

文字や名前が読めない、アイコンが隠れる、配置が異なる場合は取りこぼす可能性があります。公式案内がユーザー発言と同じ画像・名前・本文の並びなら、見た目だけでは区別できない場合があります。画面・認識本文の保存や送信はしません。配信ログは件数と処理時間のみです。

## 開発

```
bash scripts/test-core.sh
python3 scripts/generate-project.py
```

Apple環境では `bash scripts/test-native.sh`。CIではシミュレーターとiPhone用バイナリをビルドし、iPhone用だけを署名前IPAにまとめます。IPAそのものを直接開いても署名なしではインストールできません。
