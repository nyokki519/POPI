# GRAVITY Comment Reader 設計

目的：Macに表示したiPhoneのGRAVITYコメント欄から新しいコメントを読み上げる。ユーザーの自律実装指示に従い設計・実装を同一作業で進める。

- macOS 14以降。Apple Silicon / Intel。Swift、AppKit、ScreenCaptureKit、Vision、AVFoundation、CoreAudio。実行時の外部API・Python・追加パッケージ不要。
- USBのQuickTime「新規ムービー収録」でiPhoneを表示する想定。macOSのiPhoneミラーリングでも画面表示できれば選択可能。ミラーリング自体をアプリが操作しない。
- 画面上の矩形領域をユーザーがドラッグ選択。500ms間隔で選択領域のみ撮影。画像とコメントはディスク保存・外部送信しない。OCR処理は非重複、失敗時は次回に復帰、再選択で停止・初期化。
- 日本語・英語OCR。文字列と位置を使って画面順に整列し、システム定型表示を除外。各コメントを2フレーム連続で確認して確定。起動時は基準化のみ。順序付き差分で末尾の新規コメントを検出。画面の重なりが消失した場合は再基準化。
- 同文が画面末尾へ追加された場合は個数を区別する。同じ文字列で同じ画面のまま流れたケースはOCRだけでは識別できない。コメントと投稿者名が別行の場合の完全な構造化も保証しない。プレビューでOCR結果を確認可能。
- 発話キュー最大8件、待機10秒超は破棄、長文は120文字。現在の発話以外のバックログを制限。開始・停止・領域変更・音声設定変更で保留発話を破棄。即時停止対応。
- PRIVATE：Macの出力デバイスを選び自分が聞く。ROOM：仮想／物理音声デバイスを選択し、アプリ内の音声だけを出力。iPhoneへの入力は機器／配線／GRAVITY側のマイク選択が別途必要。BlackHoleを選んでもiPhoneへ自動送信されない。
- UI：開始停止、領域選択、モード、出力、声、速度、除外語、診断、テスト発話、OCRプレビュー、処理時間、発話待機件数。モード変更時に音声を停止しROOMへの意図しない発話を防ぐ。
- double-click起動：起動.commandでMac上に.appをビルドし開く。初回のみApple Command Line Toolsが必要。ダウンロードされた未署名アプリのGatekeeperを無効化しない。開けない場合はOS標準の許可手順を案内。
- Linuxで同じSwiftコアを実行テスト。Mac APIコードは構文検査まで。実機がない工程を動作済みと記載しない。
