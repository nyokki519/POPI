# GRAVITY Comment Reader

iPhoneのGRAVITYコメントをMacで読み上げるアプリの初版です。**Mac固有のビルド・画面取得・音声出力は、現在のLinux環境では実機検証できていません。** 同じSwiftコメント処理の30テストと模擬再生は検証済みです。

## 最初の起動

1. ZIPを展開し、**起動.command** をダブルクリックします。初回だけApple Command Line Toolsのインストール画面が出る場合があります。インストール完了後、同じファイルをもう一度開きます。
2. アプリが生成されて開きます。初回ビルド時にコメント処理と日本語OCRの自己検査を自動実行します。失敗した場合はアプリを開かず、エラーを表示します。
3. iPhoneをMacに表示し、アプリの「コメント欄を選択」で文字の領域をドラッグします。
4. 出力先を選び「テスト読み上げ」で音を確認してから「開始」を押します。画面収録許可を求められたらOSの設定で許可し、アプリを再起動します。

macOS **14以降**、Intel／Apple Silicon対応を想定。フルXcode・Python・有料API・外部サービス登録は不要です。生成先は `~/Library/Application Support/GravityCommentReader/build/GRAVITY Comment Reader.app`。初回以降はこの.appを直接開くこともできます。ソースが変わった場合は起動.commandから再ビルドしてください。

macOSがダウンロードしたランチャーの起動を止めた場合は、ファイルを開く操作の後に「システム設定 → プライバシーとセキュリティ」の「このまま開く」など、OS標準の許可操作を使ってください。OS保護の無効化は不要です。

## iPhoneを表示する

PRIVATEの基本経路は **USB接続 → QuickTime Player → ファイル → 新規ムービー収録 → カメラにiPhoneを選択** です。iPhoneのロック解除と「このコンピュータを信頼」の操作が必要です。録画開始は不要です。iPhone側でGRAVITYのコメント画面を開きます。QuickTimeのマイクにはiPhoneを選ぶ必要はありません。

macOSの「iPhoneミラーリング」でも表示領域を選べますが、Appleはこの機能でのiPhoneカメラ・マイク利用を提供していません。**iPhoneミラーリングはPRIVATE向けとし、ROOMのマイク利用には別の表示経路を検証してください。**

表示ウィンドウを移動・拡大縮小した場合は範囲を選び直してください。コメント以外の見出し・名前・ボタンを含めるとそれも文字として認識される場合があります。OCRプレビューで対象を確認できます。

## PRIVATE / ROOM

- **PRIVATE**：Macのスピーカー／ヘッドホン等に出力し、自分が聞くモードです。
- **ROOM**：選んだMacの仮想／物理音声デバイスに、読み上げ音を出力するモードです。モード変更時は発話とキューを停止します。Mac全体の標準出力は変更しません。

**ROOMを選ぶだけではiPhoneのGRAVITYに送信されません。** BlackHole等はMac内の仮想音声経路であり、iPhoneのマイク入力を自動作成しません。iPhone対応USBオーディオ機器／ミキサー等の入力経路と、GRAVITY側の発言・マイクONが必要です。機器の購入・インストールは自動実行していません。

アプリの「接続診断」はMac側のデバイス有無・画面権限・日本語音声を表示します。iPhoneへの接続やルーム参加者に聞こえるかは検出できません。別の参加者／端末での確認が必要です。USB画面表示とUSB音声入力が同時利用できない構成では、別の画面表示方式も必要です。具体的な機器構成は未検証です。

## コメントの扱い

- 500msを目標間隔として撮影・OCRを順次実行。処理中に次のOCRは重ねません。
- 最初の画面は基準化のみ。各新規文字列を2フレーム連続で確認後、表示順に読み上げます。
- スクロール前後の文字列の重なりを照合し、同文の追加個数も区別します。重なりがなくなった場合は再基準化して、古い履歴の一括発話を避けます。
- 発話待機最大8件、10秒を超えた待機は破棄、1件120文字まで。多量の投稿はすべてを読まず、古い待機を減らします。すでに発話中の文章は「停止」まで継続します。
- 「入室しました」等の定型行を除外。任意の除外語句も指定可能。
- 同じ文章・同じ画面で変化が見えない新規投稿はOCRだけでは識別できません。OCR誤読・高速スクロールでは見落とす場合があります。名前と本文が別行の場合や折り返しは、行単位の読み上げになります。
- 画像・コメントをディスク保存／外部送信しません。保存する設定は音声・速度・除外語句だけです。

## iPhoneがないとき

「模擬コメントで試す」は実際の検出器・キューにテスト用文字列を入力し、選択した出力で発話します。模擬モードでは画面OCRを実行しません。Mac音声そのものは実機で確認してください。

## 不具合の確認

- 画面取得できない：OSの画面収録権限を許可してアプリを再起動。範囲を再選択。
- 読み上げない：OCRプレビュー、出力先、日本語音声、除外語句を確認。最初の画面は読み上げません。
- 日本語音声がない：Macのシステム設定で日本語の読み上げ音声を追加。
- 出力が切れた：自動停止します。再接続し「出力を更新」を押します。
- ビルドに失敗：起動画面のエラーと `~/Library/Logs/GravityCommentReader/build.log` に記録します。古いSDKの場合はApple Command Line Toolsを更新。

詳しい検証範囲は [docs/verification.md](docs/verification.md)。開発用テストは `bash scripts/test-core.sh`、Macでの追加検査は `bash scripts/test-mac.sh`。実機検証を終えるまで、ROOM配信やMac上の動作を検証済みとは扱いません。
